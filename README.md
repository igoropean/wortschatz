# Mein Wortschatz – German vocabulary PWA

2,000 German words with search, filters, flashcards, learned/bookmark tracking, a progress dashboard and verb conjugation tables. Works offline once installed.

## Deploy on GitHub Pages
1. Create a new GitHub repository (e.g. `wortschatz`).
2. Upload **all files and the `icons` folder** to the repository root (Add file → Upload files).
3. Go to **Settings → Pages**, set Source to *Deploy from a branch*, choose `main` and `/ (root)`, then Save.
4. After a minute your app is live at `https://<your-username>.github.io/wortschatz/`.

## Install on your phone
- **Android (Chrome):** open the link, tap **Install app** in the app header (or ⋮ → *Install app*).
- **iPhone (Safari):** open the link, tap Share → **Add to Home Screen**.

## Updating
After changing any file, edit `CACHE = "wortschatz-v1"` in `sw.js` to a new value (e.g. `v2`) so installed copies refresh.

## Your data
Added words, bookmarks and learned words are saved in the browser on that device. Use **Backup → Copy backup** to move them between devices.
